## 实战前置条件

- [ ] 使用独立测试钱包，余额严格受限。
- [ ] 私钥和 API Key 未进入仓库、日志或截图。
- [ ] 合约、网络、授权、金额和退出方案已确认。
- [ ] 模拟成功，净利润和最大损失均符合阈值。
- [ ] 紧急停止与失败恢复流程可用。

## 执行步骤

1. 记录信号及其区块状态。
2. 生成交易计划并完成风控检查。
3. 执行最新状态模拟。
4. 人工确认并签名（如进入真实资金测试）。
5. 广播、跟踪确认并保存 receipt。
6. 计算实际 PnL 并完成复盘。
