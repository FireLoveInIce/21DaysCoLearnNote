# Day 06 学习记录：DEX 内套利

## 今日目标

- 理解同一 DEX 内不同池或不同路径之间的价差来源。
- 按“为什么出现、执行条件、最容易死在哪里”分析机会。
- 建立一套包含成本的净利润判断公式。

## 场景分析框架

### 为什么出现

- 不同费率池、不同路由或状态更新速度造成的短暂价格差。
- 大额交易造成局部价格偏移，需要套利交易恢复价格。

### 执行需要什么条件

- 同一区块或足够接近的池状态。
- 可执行路径、充足流动性、合理 gas 和可控滑点。
- 原子执行或能够控制中间资产暴露。

### 最容易死在哪里

- 报价使用旧状态、抢跑、手续费遗漏、精度错误、交易回滚。
- 理论价差存在，但交易规模导致价格影响吞噬利润。
