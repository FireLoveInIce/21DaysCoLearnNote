# Day 10 学习计划：同链套利复习与巩固

## 今日定位

今天不再扩展清算等新方向，而是回到最接近当前技术栈、也更适合个人建立第一版系统的同链套利场景：DEX 内套利、DEX 间套利和三角套利。

目标不是重复背概念，而是把 Day 06、Day 07 和 Day 09 的知识合并成一套统一分析方法，并通过同一个案例完成报价、规模扫描、成本计算、模拟和失败分析。

## 今日目标

- 重新解释三类同链套利为什么出现，以及它们之间的区别和重叠。
- 能从池状态计算指定交易规模下的真实输出，而不是只比较展示价格。
- 能判断一条路径是否可以在同一笔交易中原子执行。
- 能把手续费、Gas、滑点、排序费用和失败成本纳入净利润。
- 能对一个具体候选机会给出“放弃、监控或继续模拟”的结论。

## 一、三类同链套利为什么出现

### 1. DEX 内套利

同一个 DEX 中可能同时存在：

- 相同交易对的不同费率池。
- V2、V3、V4 等不同版本或不同流动性模型。
- 直接兑换和经过中间资产的间接路径。
- 独立接受订单流、尚未完成价格同步的多个池。

池子只会在交易发生时更新自己的状态，不会主动与其他池保持价格一致。因此，同一个 DEX 内也会短暂出现指定规模下的可成交价差。

### 2. DEX 间套利

不同 DEX 的流动性、用户订单流、费率和价格曲线彼此独立。同一个交易对在两个 DEX 上受到不同交易冲击后，可能形成短暂价差。

真正比较的不是两个页面显示的中间价格，而是：

```text
DEX A 买入指定数量的实际总成本
DEX B 卖出相同数量的实际总所得
```

### 3. 三角套利

三个交易对的隐含汇率可能暂时不一致，例如：

```text
USDC → WETH → TOKEN → USDC
```

如果完整闭环后取回的 USDC 多于投入的 USDC，才存在候选机会。三角套利既可以发生在同一个 DEX，也可以跨多个 DEX，因此它描述的是“路径形状”，而 DEX 内、DEX 间描述的是“交易场所关系”。

## 二、共同的可执行条件

### 1. 资产必须被正确识别

不能只使用 Token Symbol。至少需要确认：

```text
chain_id
contract_address
decimals
是否原生或封装资产
是否桥接资产
是否存在税、黑名单、暂停或升级权限
```

地址不同的同名资产不能默认等价。

### 2. 池状态必须来自一致快照

- 所有池应固定在同一个 `block_number` 或可靠的同一状态快照。
- 记录区块哈希、链上时间、本地接收时间和数据年龄。
- Subgraph 可以发现池和做历史分析，但最终报价应读取链上状态或调用真实 Quoter。

如果池 A 来自区块 N、池 B 来自 N-2，价差可能只是数据不同步。

### 3. 必须计算指定规模的真实报价

对于每一跳：

```text
上一跳 amount_out = 下一跳 amount_in
```

报价必须包含池手续费和价格影响，并遵守合约的整数舍入规则。至少扫描多个输入规模，例如：

```text
100 / 500 / 1,000 / 5,000 / 10,000 USDC
```

机会通常存在一个最佳规模：规模太小无法覆盖 Gas，规模太大会被滑点吞噬。

### 4. 完整路径应尽量原子执行

同链路径应放入同一笔交易：

```text
读取起始资产余额
→ 执行所有兑换
→ 检查最终余额
→ 利润不足则整体回滚
```

原子回滚可以避免留下中间资产，但不能退回已经消耗的 Gas。

### 5. 最终交易必须重新模拟

候选路径通过本地计算后，还需要：

- 调用协议 Quoter 校验报价。
- 使用真实发送方、余额、授权、Router 和 calldata 执行 `eth_call`。
- 检查最终余额差、Gas 消耗和回滚原因。
- 新区块出现或关键池状态变化后重新报价和模拟。

## 三、统一利润模型

```text
gross_profit = final_base_asset - initial_base_asset

net_profit =
    gross_profit
    - gas_cost
    - priority_or_builder_fee
    - flash_loan_or_borrow_fee
    - expected_failure_cost
    - risk_buffer
```

如果 Router 或 Quoter 给出的 `amountOut` 已经包含 LP 手续费和价格影响，就不要再次重复扣除。

### 示例

```text
投入                         10,000 USDC
完整路径最终输出             10,105 USDC
毛利润                          105 USDC
Gas                              28 USDC
排序或私有提交费用                 9 USDC
预期失败成本                       8 USDC
安全缓冲                          15 USDC

净利润 = 105 - 28 - 9 - 8 - 15 = 45 USDC
```

表面收益率为 `1.05%`，真正可保留的净收益率只有 `0.45%`。

## 四、三类场景对比

| 场景 | 路径特点 | 主要优势 | 主要成本 | 最容易死在哪里 |
| --- | --- | --- | --- | --- |
| DEX 内 | 同一 DEX 的多池、费率层级或路由 | 接口和资产模型相对统一 | 多跳费率、Gas | 重复池、错误费率、路径滑点 |
| DEX 间 | 在不同 DEX 之间买低卖高 | 路径直观、候选池较多 | 两边手续费、Gas、排序成本 | 只看展示价、代币行为不同、被抢先 |
| 三角套利 | `A → B → C → A` 闭环 | 不需要外部美元价格即可判断闭环 | 多跳费用、舍入和更高 Gas | 某一跳深度不足、路径过长、输出传递错误 |

三者都不能仅凭 Spot Price 判断，都需要按规模执行完整闭环。

## 五、最容易死在哪里

### 1. 把价格差当作利润

两个池价格不同只代表存在候选信号。指定规模成交后的平均买入价可能已经高于平均卖出价。

### 2. 低估滑点和流动性分布

V3 的流动性分布在不同 Tick 中。当前 Tick 附近价格看起来很好，不代表大额交易跨 Tick 后仍然盈利。

### 3. 使用过期状态

计算、模拟、签名和广播之间都会产生延迟。其他交易可能先改变池状态，使利润减少或触发回滚。

### 4. 忽略非标准代币与 V4 Hook

税币、rebasing token、黑名单、动态手续费和修改 Swap Delta 的 Hook，都可能使标准 AMM 公式失效。

### 5. 被抢跑或竞价吞噬利润

公开提交会暴露路径。竞争者可能复制交易、提高优先费或先改变目标池状态。私有提交只能降低部分风险，不能保证成交。

### 6. 只统计成功交易

策略评估必须包含失败交易消耗的 Gas：

```text
expected_profit =
    success_probability × profit_if_success
    - failure_probability × gas_if_failed
```

## 六、今日学习安排

### 阶段 1：复述与画图（约 45 分钟）

- 分别用一句话解释 DEX 内、DEX 间和三角套利。
- 各画一条资金路径。
- 标出哪些场景可以互相重叠。

### 阶段 2：固定历史区块计算（约 1.5 小时）

- 选择一条 EVM 链、一个基础资产和 2–3 个池。
- 固定历史区块读取池状态。
- 扫描至少五个输入规模，并记录每一跳真实输出。

### 阶段 3：成本与压力测试（约 1.5 小时）

- 计算毛利润、Gas、排序费用、失败成本和净利润。
- 分别把 Gas、输入规模和目标池状态向不利方向调整。
- 找出盈亏平衡规模、最优规模和最大允许状态变化。

### 阶段 4：模拟与结论（约 1 小时）

- 构造完整路径的最终 calldata。
- 使用同一状态执行 `eth_call` 或本地 fork 模拟。
- 根据模拟结果给出“放弃、监控或继续模拟”的结论。
