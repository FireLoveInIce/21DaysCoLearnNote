# Day 07 学习记录：DEX 间套利

## 今日目标

- 理解相同资产在不同 DEX 之间产生价差的原因。
- 比较不同 AMM 模型、手续费与流动性深度。
- 能够判断一条跨 DEX 路径是否具有可执行空间。

## 场景分析框架

### 为什么出现

- 各 DEX 的流动性、订单流、手续费和定价模型不同。
- 同一市场事件传导到不同池的速度存在差异。

### 执行需要什么条件

- 统一 token、decimals、价格基准和区块状态。
- 买入与卖出腿能够原子执行，或具备库存与风险控制。
- 正确估算各池价格影响、gas 与协议费用。

### 最容易死在哪里

- 伪同名资产、代币税、路由错误、池深度不足、状态竞争。
- 只比较现价，没有按计划交易量计算真实成交价。
