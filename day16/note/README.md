# Day 16 学习记录：可观测性、回放与监控验收

## 今日目标

- 让系统的每个信号都可追踪、可解释、可回放。
- 建立日志、指标、告警和历史案例验证链路。
- 验收“类似事件再次发生时能够快速捕捉信号”。

## 学习框架

1. 如何为区块、事件、报价、信号和任务建立关联 ID？
2. 哪些指标能够反映数据延迟、漏块和信号质量？
3. 如何用历史区块重放而不依赖未来数据？
4. Cloudflare Workers、D1、KV/Cache 可承担哪些监控职责？
