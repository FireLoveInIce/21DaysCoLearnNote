# Day 08 学习记录：跨链套利

## 今日目标

- 理解跨链市场分割、桥接延迟与库存套利。
- 区分“交易后再跨链结算”和“预置资金两边成交”。
- 建立跨链场景的时间、资金与技术风险清单。

## 场景分析框架

### 为什么出现

- 不同链上的流动性、需求、费用和信息传导速度不同。
- 跨链桥存在延迟、额度和资产形态差异。

### 执行需要什么条件

- 两条链都有可用资金、稳定节点和可靠报价。
- 明确桥接路径、最终性、到账时间和再平衡成本。
- 能够承担非原子执行期间的价格与库存风险。

### 最容易死在哪里

- 桥接延迟或暂停、重组、资产脱锚、Gas Token 不足。
- 两条链分别成交导致单腿暴露，或价差在到账前消失。
