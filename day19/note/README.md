# Day 19 学习记录：密钥安全与半自动确认

## 今日目标

- 设计不暴露私钥的签名流程。
- 实现“系统生成交易，由本人确认后签名”的半自动模式。
- 建立金额、合约、网络和权限的人工确认清单。

## 学习框架

1. 观察钱包、执行钱包和资金钱包是否应分离？
2. 私钥、助记词和 API Key 应保存在哪里？
3. 人工确认页面必须展示哪些可读信息？
4. 如何防止错误网络、恶意合约、无限授权和地址替换？

## 动手任务

- [ ] 设计观察、构造、审批、签名、广播的流程。
- [ ] 确认 `.env`、日志和数据库不会保存敏感材料。
- [ ] 设置地址白名单、金额上限和函数选择器白名单。
- [ ] 建立紧急停止、撤销授权和密钥轮换方案。

## 签名前检查清单

- [ ] chain ID 与预期网络一致。
- [ ] to 地址与合约代码哈希已确认。
- [ ] token、数量、最小输出和 deadline 可读且合理。
- [ ] 授权额度、gas 上限和最大损失未超过阈值。
- [ ] 最新模拟通过，状态没有明显过期。
