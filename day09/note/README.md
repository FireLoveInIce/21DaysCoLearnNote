## 今日目标

- 理解稳定币偏离锚定价格时的套利和风险。
- 能够过滤表面盈利但实际不可执行的路径。

## 场景分析框架

### 为什么出现

- 多个交易对之间的隐含汇率短暂不一致。
- 稳定币供需、流动性、信用和赎回预期发生变化。

### 执行需要什么条件

- 路径能够回到初始资产，且每一跳都有足够深度。
- 完整计算各跳手续费、价格影响、gas 与代币特性。
- 稳定币具备可信的赎回、铸造或外部价格参照。

### 最容易死在哪里

- 路径组合爆炸、精度累积误差、代币税或 transfer 限制。
- 把真实脱锚风险误判为无风险价差。
